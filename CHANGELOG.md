# Changelog

- First shareable package: native rules, overlay, setup/removal helper, tests,
  documentation, screenshot and MIT license.
- Configuration integration uses a marked block, makes a backup, refuses edited
  blocks and restores prior configuration on setup failure.
- Retains the verified screensaver exclusion and theme-aware color selection.
